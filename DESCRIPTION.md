# Модель предметной области

# Краткое описание
Модель описывает систему, где пользователь регистрируется в банковской системе и получает определенную роль. Пользователь может открыть один или несколько счетов.

Между счетами могут выполняться транзакции. Каждая транзакция переводит определенную сумму с одного счета на другой и имеет собственный статус.

Для контроля изменений предусмотрены журналы аудита. Они позволяют хранить историю изменений по пользователям и счетам.

---

## Пользователь
Поля:
- `id` - идентификатор пользователя;
- `login` - логин пользователя;
- `name` - имя;
- `last_name` - фамилия;
- `role_id` - роль пользователя;
- `password_hash` - хэш пароля;
- `created_at` - дата создания пользователя;
- `blocked_at` - дата блокировки, если пользователь заблокирован.

Связи:
- один пользователь имеет одну роль;
- один пользователь может иметь много счетов;
- изменения данных пользователя фиксируются в `users_audit_log`.

## Роль
(клиент, менеджер, старший менеджер, технический специалист)

Поля:
- `id` - идентификатор роли;
- `name` - название роли.

## Счёт
Поля:
- `id` - идентификатор счета;
- `number` - номер счета;
- `user_id` - владелец счета;
- `balance` - баланс счета;
- `type_id` - тип счета;
- `status_id` - статус счета;
- `created_at` - дата создания счета.

Связи:
- каждый счет принадлежит одному пользователю;
- каждый счет имеет один тип;
- каждый счет имеет один статус;
- один счет может участвовать во многих транзакциях как счет-отправитель;
- один счет может участвовать во многих транзакциях как счет-получатель;
- изменения данных счета фиксируются в `account_audit_log`.

## Тип счёта
(дебетовый, кредитный, накопительный, счёт банкомата/технический)

Поля:
- `id` - идентификатор типа счета;
- `name` - название типа счета.

## Статус счёта
(активен, заблокирован, закрыт, заморожен)

Поля:
- `id` - идентификатор статуса;
- `name` - название статуса.

## Транзакция
Поля:
- `id` - идентификатор транзакции;
- `from_account_id` - счет-отправитель;
- `to_account_id` - счет-получатель;
- `amount` - сумма перевода;
- `status_id` - статус транзакции;
- `created_at` - дата создания транзакции.

Связи:
- каждая транзакция связана с одним счетом-отправителем;
- каждая транзакция связана с одним счетом-получателем;
- каждая транзакция имеет один статус.

## Статус транзакции
(создана, выполнена, отклонена, отменена)

Поля:
- `id` - идентификатор статуса;
- `name` - название статуса.

## Журнал аудита пользователей
Фиксирует изменения в таблице `users`.

Поля:
- `id` - идентификатор записи аудита;
- `user_id` - пользователь, у которого изменились данные;
- `field` - измененное поле;
- `old_value` - старое значение;
- `new_value` - новое значение;
- `changed_at` - дата изменения.

## Журнал аудита счетов
Фиксирует изменения в таблице `accounts`.

Поля:
- `id` - идентификатор записи аудита;
- `account_id` - счет, у которого изменились данные;
- `field` - измененное поле;
- `old_value` - старое значение;
- `new_value` - новое значение;
- `changed_at` - дата изменения.

# User stories

## Пользователь
| User story                                                                 | Результат                                                             | Ограничения                                                                         |
| -------------------------------------------------------------------------- | --------------------------------------------------------------------- |-------------------------------------------------------------------------------------|
| Как пользователь, я хочу перевести деньги другому человеку по номеру счета | Баланс моего счета уменьшается, баланс счета получателя увеличивается | Счет отправителя принадлежит пользователю, активен, не заморожен, баланс достаточен |
| Как пользователь, я хочу открыть новый счет или вклад                      | Создается новый счет пользователя                                     | Пользователь не заблокирован                                                        |
| Как пользователь, я хочу перевести деньги между своими счетами             | С одного моего счета списывается сумма, на другой зачисляется         | Оба счета принадлежат пользователю, активны, баланс достаточен                      |
| Как пользователь, я хочу пополнить счет через банкомат                     | Баланс счета увеличивается                                            | Счет принадлежит пользователю и активен                                             |
| Как пользователь, я хочу снять деньги со счета                             | Баланс счета уменьшается                                              | Счет активен, баланс достаточен                                                     |
| Как пользователь, я хочу посмотреть информацию о счете                     | Отображаются номер счета, тип, статус, баланс                         | Только свои счета                                                                   |
| Как пользователь, я хочу закрыть счет                                      | Счет получает статус закрытого                                        | Баланс нулевой                                                                      |
| Как пользователь, я хочу заморозить счет                                   | Операции по счету становятся недоступны                               | Только свой активный счет                                                           |
| Как пользователь, я хочу сменить логин или пароль                          | Данные входа изменены                                                 | Возможно, нужен ввод текущего пароля                                                |
| Как пользователь, я хочу посмотреть операции по счету                      | Отображается список транзакций по счету                               | Только по своим счетам                                                              |

| Как менеджер, я хочу создать пользователя                | Новый пользователь зарегистрирован                             | Логин уникален                                   |
| Как менеджер, я хочу удалить пользователя                | Система возвращает ошибку                                      | Вместо удаления используется блокировка          |
